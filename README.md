# Raghvendra Portfolio

A responsive, animation-heavy developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Simply open `index.html` in a browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Replace these before publishing

1. `YOUR_EMAIL@example.com` in `index.html`
2. GitHub URL
3. LinkedIn URL
4. Add your actual project screenshots/videos to:
   - `assets/images/`
   - `assets/videos/`
   - `assets/models/`
